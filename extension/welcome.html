ClarkReader

Select text, press Alt+R, hear it read in the Emma voice while each word flashes up as she says it.

The voice is synthesized on your own machine by a small local server. Nothing you read is sent anywhere. That server has to be installed and running before the extension can do anything, so this page is the one step that matters.

1. Install the server (once)

You need Git and about 2 GB of disk for the model. The setup script finds a Python Kokoro supports (3.10, 3.11 or 3.12; it does not install on 3.13 or newer) and on Linux and macOS can fetch one for you if there is none.

Linux / macOS — in a terminal:

git clone https://github.com/CryptoJones/ClarkReader.git
cd ClarkReader
./install.sh

install.sh builds a virtual environment, installs the server, builds the extension into dist/, and starts the server at every login: a systemd user service on Linux, a launchd agent on macOS. If there is no Python 3.10 to 3.12 it offers to install uv into ~/.local/bin to fetch one. Run it again any time; ./install.sh --no-autostart removes the login service.

Windows — install Python 3.12 (tick Add python.exe to PATH) and Git, then in PowerShell:

git clone https://github.com/CryptoJones/ClarkReader.git C:\ClarkReader
cd C:\ClarkReader
powershell -ExecutionPolicy Bypass -File install.ps1

install.ps1 finds a Python Kokoro supports (it does not install on 3.13 or newer, so it looks for 3.12, 3.11, then 3.10), builds a virtual environment, installs the server, builds the extension into dist\, adds a shortcut to your Startup folder so the server starts at every login, and starts it now. Run it again any time; -NoAutoStart removes the login shortcut. It is per-user and needs no admin rights.

Clone somewhere with a short path such as C:\ClarkReader: PyTorch has deep file paths, and the install fails with a "long path" error from a deeply nested folder unless Windows long paths are enabled. The install pulls PyTorch, which is a large download. If Windows Firewall asks whether Python may accept connections, allowing private networks is enough; the server only listens on your own machine unless you point it elsewhere. Tested on Windows 11 with Python 3.12 on a CPU; if something here does not work for you, please open an issue.

The first start downloads the Kokoro model and the Emma voice, then says it is listening on http://127.0.0.1:8756. The first start is slow, a couple of minutes on a CPU, because it also fetches a small language model for text handling. After that it runs fully offline. The setup scripts run it in the background, so there is no terminal to keep open.

The README has what hardware the server needs and how to run it by hand. The setup was tested on Ubuntu 26.04 (under WSL), macOS 26 on Apple silicon, and Windows 11. On the Mac the extension was also confirmed working in Chrome.

The scripts build the extension but a browser will not load one silently. Load it once: in Chrome, chrome://extensions → Developer mode → Load unpacked → the dist/chrome folder inside the ClarkReader folder. In Firefox, about:debugging#/runtime/this-firefox → Load Temporary Add-on → dist/firefox/manifest.json; Firefox forgets a temporary add-on when it closes.

2. Check the connection

Click the ClarkReader toolbar icon. The popup shows a green dot and kokoro ready when the server is up. On Firefox, the first time, it will ask you to Allow access to the server; that is Firefox's opt-in for local connections and is expected.

3. Read

Alt+Rread the selection, or the whole page if nothing is selected
Alt+Ppause / resume
Alt+Sstop
Alt+Mmaximize the reader to the whole tab; Esc brings it back
right-clickRead aloud with Emma on a selection, Read entire document with Emma anywhere

A document you stop partway through remembers its place; reading it again picks up there, and the popup offers Resume reading document.

If a shortcut clashes with a site you use, change it in your browser's extension shortcut settings (chrome://extensions/shortcuts in Chrome, Manage Extension Shortcuts in Firefox).

Using a server on another machine

The server can run on any machine on your network, which is how a Chromebook can use it. Put its address in the popup's Server field, then click Allow access to the server when the popup asks; the extension only ever has permission for the address you give it.

Privacy

ClarkReader sends the text you ask it to read to the server address you configured, which by default is your own machine, and receives audio back. It stores your voice and speed settings, whether the reader is maximized, and where you stopped in documents you read whole. It collects nothing, has no analytics, and makes no other network connections. The full policy is in the README.
