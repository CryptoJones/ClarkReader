# Backlog

This file and the GitHub **Issues tab** are two views of the same list and must stay
in sync. Every open item below gets a matching GitHub issue when the repo is published.

## Open

- [ ] **Highlight the sentence being read** — _feat_ — the player already knows the active chunk index; map chunks back to Range offsets in the original selection and paint them in the page.
- [ ] **Read PDFs** — _feat_ — Chrome's viewer refuses injection; fetch the file (activeTab grants the origin), extract text page by page with a vendored pdf.js in the offscreen document, and stream pages to `/prepare` as they come. Scanned PDFs have no text layer and would need OCR, which is out of scope.

- [ ] **Pronunciation overrides** — _feat_ — a user dictionary for names and jargon Kokoro gets wrong, applied in `normalize()`.

## Done

- [x] **Long words fit the word window** — _fix_ — the pivot letter is pinned to the centre of the RSVP box, so each half of a word only had half the width and a long tail past the pivot ("CryptoJones/OSApplyTrack" pivots on its fifth letter) was clipped. `renderWord` now measures both halves with a Range and scales the font so the longer one fits; when that would drop under 12px (a bare URL) the pivot drifts and the whole token is fitted to the full box, floored at 10px. A ResizeObserver refits on maximize and window resize. Verified with real font metrics in both the 340px card and the maximized box. v1.2.4.
- [x] **Firefox: signed unlisted 1.2.2, listed 1.2.3 submitted** — _chore_ — `sign.sh` signed 1.2.2 unlisted (add-on 3071294 now bound to CJ's AMO account); 1.2.3 is the first listed submission since AMO refuses a repeated version number. `store/amo-listing.md` carries the listing text and `store/amo-metadata.json` what `sign.sh --listed` sends (license, categories, summary, description, links, release and reviewer notes); AMO rejected the upload field by field until those were present.
- [x] **`sign.sh` for Firefox** — _chore_ — regular Firefox drops temporary add-ons on exit and refuses the unsigned zip; `sign.sh` builds and runs `web-ext sign` (unlisted by default, `--listed` for the store) reading `WEB_EXT_API_KEY`/`WEB_EXT_API_SECRET` from the environment, never printing them, and reports the `.xpi` path. `web-ext-artifacts/` ignored.
- [x] **Stale background self-heal, and store images** — _fix_ — Chrome reads a popup from disk on every open but keeps the background worker it loaded at startup, so an updated unpacked extension is a new popup talking to an old worker ("Read entire document" answered "Nothing selected."). The popup now compares the manifest on disk with the version the background reports (`cr-version`) and calls `runtime.reload()` on a mismatch or no answer. `store/` holds the three 1280x800 screenshots, the 440x280 tile and the 1400x560 marquee, rendered by headless Chrome from the real overlay and popup. v1.2.2.
- [x] **EPUBs** — _feat_ — `tools/read_epub.py` (stdlib only) unpacks an EPUB, writes `index.html` (cover, author, chapter list from nav/NCX/first heading) and `book.html` (all chapters in spine order with image and stylesheet paths relocated), appends prev/next/contents links to each chapter file, and opens it. Whole-document cap raised to 1M characters now that memory is bounded per sentence; the unused chunk list is no longer sent to the overlay. Requires "Allow access to file URLs" once in Chrome. v1.2.1.
- [x] **Store readiness** — _chore_ — server CORS answers extension origins only (a web page could previously drive a user's synthesizer from Firefox); `minimum_chrome_version` 116; `homepage_url`; `optional_host_permissions` for a LAN server, granted per address from the popup's existing button; a `welcome.html` setup guide opened on install, from the popup and from every "cannot reach the server" error; permission justifications and a privacy policy in the README; `build.sh` packs the store zips; dead `showOverlay` setting removed; shortcut rebinding note. v1.2.0.
- [x] **Resume a whole-document read** — _feat_ — the sentence index is written to `storage.local` under the page URL (sans fragment) after every sentence of a whole-document read; stop keeps it, finish clears it. The next whole-document read of that URL resumes there (`from` on the play message, the player clamps it), the popup shows **Resume reading document · n / N** and its **Read entire document** restarts. A bookmark whose sentence count no longer matches the page is dropped. Capped at 100 pages. v1.2.0.
- [x] **Long reads bounded in memory, bad sentences skipped** — _perf_ — per-job audio cache on the server keeps `KEEP_BEHIND` sentences behind the playhead plus the client's prefetch, evicting the rest (a whole document had been hundreds of MB per job); the player skips a sentence that fails to synthesize or decode and stops only after three in a row; pages over 40k DOM nodes bypass Readability's clone-and-walk. v1.2.0.
- [x] **Read the entire document** — _feat_ — with nothing selected, `Alt+R` reads the page's main content; a **Read entire document with Emma** context-menu item and a popup button do so even over a selection. Extraction is Mozilla Readability 0.6.0, vendored under `extension/vendor/` and injected on demand into the extension's isolated world, run against a document clone; the title is spoken first and shown in the header; visible body text is the fallback and 250k characters the cap. v1.2.0.
- [x] **Maximize the reader window** — _feat_ — ⤢ in the card header, `Alt+M` (a fourth command in both manifests) or the button; `Esc` restores, only while the card is actually showing so a hidden overlay never eats the page's Escape. The card fills the viewport with the word at `clamp(44px, 8vw, 112px)`, guide lines and bar under it, sentence and controls at the bottom. Remembered in `storage.sync` as `maximized`. v1.2.0.
- [x] **Word window (RSVP) synced to the voice** — _feat_ — the overlay flashes each word as it is spoken, Spritz-style: fixed position, red optimal-recognition letter, guide lines with a pivot tick, a progress bar and a live WPM readout. Timing is real, not estimated: Kokoro's per-token timestamps are merged into words server-side and served from a new `GET /words/<job>/<i>`; the player reports them with the playback position and a wall-clock stamp, and the overlay runs its own clock. Older servers and non-English voices fall back to length-weighted even spacing. Toggle in the popup. v1.1.0.
- [x] **Test suites for both halves** — _test_ — 7 extension tests executing the real sources against stubbed WebExtension APIs, 21 server tests over normalization and splitting. Mutation-checked: reintroducing the content-script redeclaration bug and scrambling the Firefox script order each fail exactly one test. Found and fixed a dropped sentence period on "etc.".
