# Store listing assets

Rendered by headless Chrome from the real `content.js` and `popup.html` at the exact
sizes the stores ask for. Regenerate after a visual change to the overlay or popup.

| File | Where it goes |
|---|---|
| `screenshot-1-maximized.png` | Chrome Web Store and AMO screenshot 1 (1280x800): the maximized reader mid-word |
| `screenshot-2-reader-card.png` | screenshot 2: the card over an article, selection highlighted |
| `screenshot-3-popup.png` | screenshot 3: the popup with a resume bookmark showing |
| `promo-tile-440x280.png` | Chrome Web Store small promo tile (required) |
| `marquee-1400x560.png` | Chrome Web Store marquee (optional) |

The listing's first sentence should say the local server from this repository is
required; the store shopper decides before the welcome page can tell them.
